# SubDoctor privacy policy

Public privacy-policy page for the SubDoctor Chrome extension.

This repository contains only the generated privacy page and its local styling.
It contains no extension source, subscription records, credentials, backend or analytics.

The canonical policy source is `release/PRIVACY_POLICY.md` in the local SubDoctor project.
Run `node scripts/privacy-site.mjs` there to regenerate `index.html` and `privacy.css`.
Publish these files plus `.nojekyll` and this README to the `main` branch.
GitHub Pages serves the root of `main`; verify the public page after each update.

Support and privacy contact: subdoctor.support@gmail.com.
